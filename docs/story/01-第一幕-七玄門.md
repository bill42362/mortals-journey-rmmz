## 1. 劇情大綱

序章末，韓立隨三叔離開青牛鎮，抵達**七玄門**——一個在凡人眼中高不可攀、在修仙界卻不入流的小門派。本幕是全 demo 的「**系統教學正式展開**」之地，也是核心精神「**苟是美德**／**成長是熬出來的**／**小瓶是命脈**／**資源即生命**」四者首次同時落地。

劇情分五段推進：

**段落一・落選與收徒**——韓立參加七玄門入門**考核**（世俗武行的**體能越野**：穿竹林、越亂石、攀崖，正午前登頂「**煉骨崖**」者過關），卻與好友**張鐵**雙雙**超時未過**、未列入選的內門弟子；因表現尚可、能吃苦，被留門待半年後補試。就在將被淘汰之際，門中**神手谷**的老藥師**墨大夫**驗看韓立後忽然大笑，破例收他為親傳**藥童**（張鐵亦一同收下、另授**象甲功**）。韓立就此入神手谷落腳，領一份微薄**月例（米糧＋銅板）**，親身體會門派底層的清苦——凡俗的銅板在這裡仍是命，但玩家會隱隱察覺：這不是終點。

**段落二・入神手谷·授長春功**——既入墨大夫門下，老藥師授以入門功法**《長春功》**（**功法習得**系統首秀）。韓立在神手谷藥圃打理靈草時，從土裡撿到一隻被棄置多年、不起眼的舊**綠瓶**——**瓶蓋卻怎麼也打不開**，使盡了勁也旋不動、撬不開，只當是個廢瓶隨手收著。直到一次，他連著幾夜把瓶子擱在窗台承月光，第八夜瓶身花紋忽地泛起綠光、瓶蓋應手而開，瓶底竟凝著一滴碧綠**靈液**；他摸清了這瓶的性子——**它盛不了水、養不了草，唯獨承過月光才自行凝出一滴靈液**，以此**靈液澆灌**靈草，竟能一夜暴長、藥效更盛——他悄悄藏起這個秘密（**小綠瓶**＋**靈草種植**系統首秀，「小瓶是命脈」）。作為藥童，他也在墨大夫手下學起**凡間製藥**——配藥成丸的本分手藝（**製藥／合成**系統首秀；真正點石成丹的『煉丹』小門小派授不了，留待黃楓谷），且在製藥上顯出過人的天分。

**段落三・引氣入體與藏拙**——韓立苦修長春功，撞上「凡人之壁」，在墨大夫指點與資源投入下**引氣入體、突破練氣**（**境界系統**首次突破，`凡人 → 練氣` Change Class）。突破後墨大夫搭上他的腕脈考較根底——韓立心頭一凜，收斂氣息，只讓師父探得「練氣一層」；老藥師滿意地笑了，說這塊璞玉要「好生養著」。此後師父還會時時探脈，韓立便替自己畫下一條線：**在師父面前，最多長到練氣四層**——一層不進反而可疑，可全露了，就等於供出小綠瓶。於是他一面以綠液催生的靈藥暗中猛推層數，一面在人前始終是那個進境平平、遲鈍木訥的藥童（**藏拙機制**，見 §7.8——**他藏的不只是實力，更是那隻瓶子**；這道落差，正是他日後扳倒強者的本錢）。後山藥徑（迷宮）深處，玩家經歷**首次正規回合戰鬥**（有別於序章必逃的示範遭遇）。

**段落四・疑雲與抉擇（主題高峰）**——先前的藥童一個個「得了機緣」便再沒回來；直到好友**張鐵**也被喚走、慘遭殺害煉成傀儡，韓立才驚覺真相：墨大夫**豢養藥童、殺之以煉傀儡與藥引**，更蓄謀**奪舍**——奪走一具根骨純淨、年輕合用的軀殼（他這等小門派低階修士並不通曉靈根屬性之說，只以「乾淨、合用」擇人，圖的從不是「天資高低」），而那具軀殼，正是韓立自己（墨大夫**始終未曾得手**）。他修為遠不及墨大夫——但他**苟得住**（不動聲色、佯裝無知）、**算得精**。他把小綠瓶有限的綠液**此消彼長地權衡**：一面大量催生高年份毒草、煉成毒丹當彈藥，一面分綠液催靈藥、煉補藥推進修為並備妥療傷。攤牌時他早已在墨大夫日用丹藥中下毒——毒發卻被察覺，墨大夫靈壓暴走反撲；韓立**一面以靈藥自保、一面反覆補毒**，**全程仍把修為死死壓著**，只以粗淺身手狼狽周旋，終於把這強敵毒垮。可老者不肯就此了帳——他**燃燒本命精血**拼死一搏，因為在他眼裡，面前不過是隻「練氣四層的螻蟻」。**他至死都不知道，那個木訥藥童早已熬到了練氣六層。**韓立終於卸下偽裝，長春功全力運轉、氣息節節攀升，硬生生接下那燃血一擊，再以一記樸實無華的出手了結了他。墨大夫敗得徹底，臨死卻由駭然轉為**佩服**——輸的不是修為，是看走了眼，是那份藏了多久、忍了多久的**城府**。這場**藥毒雙煉**的苦戰，是他的**第一次殺人**、**殺人奪寶**系統的預告，也親手**奠定了他日後聞名的煉丹（尤擅藥毒）天賦**。取勝的是**準備與算計**，而接住那一擊、活著走出去的，是**一夜夜熬上來的六層修為**——本作主題最直接的宣言：**準備度＞數值，而修行本身從不白費。**

**段落五・離門**——韓立繼承墨大夫的丹方、一卷**《火球術》**（**殺人奪寶**掉落雛形，也是他第一門攻伐功法），以及幾枚溫潤生涼、**他還叫不出名字的小石**（⚠️此即低階靈石，但本幕**不點破、不教學、不流通**——靈石的認知與經濟一律留給第二幕黃楓谷，見 [TECH §9.4](../TECH.md)）；更從遺物中驚覺：墨大夫所授《長春功》竟只是**上半卷**，完整功法與更上層樓（築基）的門徑，線索都指向**黃楓谷·百藥園**。對一個掌握「催生靈草」秘密的人而言，那裡才是真正的舞台。韓立悄然離門，奔赴黃楓谷（轉場第二幕）。

> **設計定調（重要，✅ 2026-09-27 定案）**：墨大夫是**反派**，非「圓滿遺憾」對象；韓立殺之為 canon 正典節點。此戰**刻意不設計成純數值 boss 硬拚**——勝負由玩家的**準備度**決定，且拆成**兩條軸**：**毒丹彈藥**（階段①，來自毒草線）與**熬出來的層數**（階段③，來自靈藥線），兩者共享同一瓶綠液。藏拙的回報則落在**階段③的揭曉**而非開場加成。完美承載四大精神——尤其是「成長是熬出來的」：**接住那燃血一擊的不是法術，是層數**。詳見 §4 EV-19/EV-20、§7.6／§7.8、[§9](#9-已收斂的待確認)。

## 2. 章節目標

### 敘事目標
- 完成韓立「由凡入仙」的第一步：從養家糊口的差事，到真正踏上修仙路。
- 立住墨大夫「**外和善、內貪婪**」的雙面，並以其之死宣示主題：**弱者靠苟與算計，也能扳倒強者**。
- 深化四大精神：資源（**本幕純凡俗經濟**：月例米糧／銅板；靈石僅以「叫不出名字的小石」混在遺澤中，價值與流通全留黃楓谷）、小瓶（秘密催生＋暗中推層）、成長（撞壁→突破的重量）、苟（**藏拙致低估**、佈局、後手）。
- 埋下「黃楓谷百藥園」的動機鉤子，銜接第二幕。

## 7. 實作備註（給 M2 內容生產 / 遊戲端）

> 以下涉及 `data/*.json`、自製外掛與共通事件，屬遊戲端工作（受編輯器鐵則約束）；本檔僅規格化，不在此次動工。**本幕是七大系統的第一個實作落點，介面應寫成可複用 CE/外掛，供後續章節呼叫。**

### 7.1 境界系統（`MJ_Realm.js`，EV-12/13）— 本幕為其首個 use case
本幕直接定義 `MJ_Realm` 的最小規格（呼應我們「文件先行、據此定外掛」的決策）：
- **職業/境界**：`凡人`（class 1，序章沿用）→ 突破後 `Change Class` 至 `練氣`（新增 class）。
- **練氣層 = 等級**：練氣以**等級區間**對應「層」（[TECH §3](../TECH.md)），突破後為**練氣一層（Lv 1）**。demo 練氣層數上限待 §9／參數草案定。
- **鏡像變數**：突破時更新境界鏡像變數（如 `V_realm`）為「練氣」，供事件條件判斷。

### 7.8 藏拙與低估（`V_a1_conceal`，EV-14/16/19/20）— 🆕 2026-09-27

**設計意圖**：貼原著「韓立靠小綠瓶暗中猛推修為、卻在墨大夫面前始終是個低層藥童」的橋段，把「**苟**」從敘事態度落實成**有數值回報的機制**。關鍵取捨：**不給玩家選單**——你越用小瓶暗中變強、越不在師父面前露底，攤牌時回報越大；玩家事後才會回味過來「原來一直藏拙是有用的」，那份「悶聲發大財」的味道正是原著的質感。

**兩個數字**

| 名稱 | 變數 | 來源 |
| --- | --- | --- |
| 真實層數 | （`MJ_Realm` 已維護的等級） | 韓立當前練氣層 |
| 認知層數 | `V_a1_moda_known` | 墨大夫探脈所見。**＝`min(真實層數, 4)`**——韓立在師父面前**最多長到練氣四層**（見下「為何是四層」） |
| 低估度 | `V_a1_conceal` | `max(0, 真實層數 − 認知層數)`，由 CE 於攤牌前結算。攤牌時（≥六層）**至少為 2** |

**為何是「四層」而不是「凍結在一層」（🔄 2026-09-27 修正）**

- **一層不動反而可疑**：韓立吃著師父配給的藥、日日修煉，若久久毫無進境，墨大夫第一個就會起疑——他是藥師，最懂藥效。**完全不長，比長得快更容易暴露。**
- **四層＝熬得辛苦卻不惹眼的數字**：對一個資源有限的藥童來說合情合理，墨大夫只會滿意地點頭說「穩當」。
- **他藏的不只是實力，是小綠瓶**：真實進境快得駭人，那是綠液催生靈藥的功勞。一旦露了，墨大夫必然追問「你哪來的藥」——**瓶子就保不住了**。這讓藏拙從單純的戰術算計，升級為**保護命脈的必要之舉**，直接扣回「小瓶是命脈」。
- 所以韓立替自己定下一條線：**在師父面前，最多四層**（`a1_narr_conceal_rule`）。這條線在 EV-14 鋪明，到 EV-20 收割。
- ⚠️ 敘事上不需為此另開事件：墨大夫偶爾探脈是日常，**韓立每次只放到他該看到的程度**；機制上直接用 `min(真實, 4)` 維護即可。

**落差怎麼拉開（正回饋）**
- EV-19 靈藥線煉的**補藥**（推練氣層）、EV-15 後山迷宮的戰鬥修為——**都不更新認知層數**。
- 墨大夫眼中的韓立**停在練氣四層**；實際上他一路熬到了**練氣六層**。這道落差就是 EV-20 揭曉的全部戲劇能量——而且揭曉的那一刻，`a1_narr_reveal_realm_02` 的氣息**正好越過四層再往上爬**，把「他以為的上限」當著他的面踩破。

**落差怎麼被抹平（自然代價，非陷阱）**
- EV-16（張鐵被選中）之後，若玩家仍反覆找墨大夫對話，他會**起疑而認真探一次腕脈**——這次韓立瞞不住 → 認知層數同步到**真實層數**、低估度歸零。
- ⚠️ 必須**在旁白明講**（`a1_mo_appraise_repeat` 的註記）：「他又探了探你的脈」，讓玩家看得見代價，而不是暗中被扣。這是「自然懲罰」不是「隱藏陷阱」。

**🔄 2026-09-27 重大修訂：回報從「開場加成」改為「高潮揭曉」**

> **原設計**：低估度 → EV-20 開場 N 回合輕敵窗口（墨大夫不暴走，韓立從容疊毒）。
> **問題**：把藏拙變成一個開場的數值 buff，玩家「用掉」它就沒了，**揭曉的戲劇性等於零**；而且毒打贏一切，顯不出修煉仙術的意義。
> **現設計**：藏拙的回報**整個移到戰鬥高潮**——墨大夫至死都以為對手是練氣四層，直到韓立在第二階段卸下偽裝。**這才是原著的寫法。**

**回報①（劇情層，主要）：EV-20 階段③的揭曉**
- 墨大夫**因為低估才選擇硬拚**（燃血一搏而非逃走求全）——**他的誤判就是他的死因**。這一點必須在台詞裡點明，否則揭曉會變成單純的炫技。
- 韓立運起長春功，氣息越過**四層**那條他自己畫的線，一路攀至**練氣六層**，墨大夫瞳孔驟縮——他追問「你哪來的藥？你哪來的時間？」，而這兩個問題的答案都是**小綠瓶**，他至死沒能想明白。臨死他由駭然轉為**佩服**：輸的不是修為，是**看走了眼**——是韓立藏了多久、忍了多久的那份**城府**。
- 這同時完成本幕的主題閉環：**「苟」不是懦弱，是把刀磨在別人看不見的地方。**

**回報②（機制層，輔助）：階段③的開場優勢與台詞分歧**
- **低估度 > 0**（正常路線）：墨大夫燃血一擊打在「他以為的練氣四層」上 → 韓立**先制＋首回合減傷**（他出手輕率、門戶大開）；臨死走**完整的「佩服城府」版台詞**。
- **低估度 = 0**（玩家在 EV-16 後反覆找墨大夫對話，被他重新探過脈）：他早有防備，**無先制、無減傷**，階段③明顯更硬；臨死台詞改為 `a1_mo_death_aware`——「老夫早看出你有異心……只是沒料到，你下手這般快。」
  - ⚠️ 這條分歧**不只是難度差，更是內容損失**：玩家會錯過整段最精彩的揭曉演出。**這比任何數值懲罰都更能教會玩家「藏拙有價」**，而且完全不需要事先警告。
- ⚠️ 仍維持**不給選單**：玩家不會被問「要不要藏拙」，只會在事後意識到自己一直在做這件事。

**實作路徑**
- EV-20 觸發前，CE 結算 `V_a1_conceal` → 存入旗標，供 troop 事件頁**階段③** 與**臨死台詞**分歧使用。
- 先制／減傷沿用 `MJ_LootAndPK` 的先攻旗標（`MJ.LootAndPK.ambush()`）＋ 一個一次性減傷 state。
- **不需新外掛**：`MJ_Realm` 給層數、原生變數記認知層數、`SkillsStatesCore` 給 state、`MJ_LootAndPK` 給先制。

**敘事收束**：EV-18 真相揭曉後，韓立才回過味來——墨大夫口中那句「好生養著」，養的從來不是徒弟，是容器。**藏拙自此從求生的本能，變成他親手磨的刀**；而到 EV-20 階段③，這把刀才第一次出鞘。

### 7.9 ⚠️ 推層管道與進度旗標（🆕 2026-09-27 回顧時補上的缺口）

> 這兩項在先前的文件裡**從未被明確指定**，但都會直接卡住實作。列此備忘。

**(A) 「熬到六層」的管道不能全擠在 EV-19**

- **問題**：EV-20 守門要求**練氣六層**（§7.6），而目前唯一寫明「補藥推層」的地方是 **EV-19 算計準備**。若玩家真的得在 EV-19 這一個事件裡從一層練到六層，會變成一段冗長的 grind，**而且和敘事對不上**——段落三明講韓立是「一路暗中熬上來」的，不是攤牌前臨時抱佛腳。
- **對策（建議）**：**EV-14 之後即開放常態循環**——藥圃催靈藥（EV-10 介面）→ 藥堂製補藥（EV-11 介面）→ 服用推層。兩個介面在 EV-10/EV-11 都已建立，**不需新系統**，只要解除門控、讓它們在 EV-14 後持續可用即可。
- **EV-19 的定位隨之收斂**為：**最後一次、有明確目的的大規模分配**（把剩下的綠液一次押在毒草⇄靈藥之間），而非唯一的推層機會。
- **副作用（正面）**：這讓「藏拙」在玩家手裡變成**一段持續的體驗**而非一個變數——每次服補藥推層，玩家都知道墨大夫眼中的自己還停在四層。
- ⚠️ 平衡連動：常態循環的推層效率須讓玩家在 EV-18～EV-19 期間自然抵達六層附近，避免守門變成卡關。併 M4。

**(B) `V_a1_progress` 的賦值點缺漏**

- **問題**：§4 只寫了 EV-03 設 `V_a1_progress=1`，但 **EV-16 的前置是 `≥2`——沒有任何事件把它設為 2**，照現況 EV-16 永遠不會觸發。
- **對策（建議賦值表）**：

  | 值 | 何時設定 | 解鎖 |
  | :---: | --- | --- |
  | 0 | 序章轉入 | EV-01/02 |
  | 1 | **EV-03 收徒完成** | 三叔道別(EV-04)、月例(EV-05)、入神手谷(M05/M06/M07) |
  | **2** | **EV-14 考較完成**（＝已突破練氣、藏拙起點已建立） | **EV-16 張鐵被選中**、後山迷宮(M08) 主線化 |
  | 3 | EV-18 真相確認 | EV-19 算計準備、EV-20 攤牌守門開始檢查 |
  | 4 | EV-21 遺澤取得 | EV-22 離門（M04 北門改走出章分歧） |

### 11.5 M08 — 七玄門·後山藥徑（**迷宮**，🔄 2026-09-27 改版）

> **改版重點**：原為線性「山林小徑」，現改為**單張大迷宮**。同時**靜室已移回 M05 打坐蒲團**（EV-12/13 不在本圖）——本圖專職一件事：**採藥冒險區**。迷宮讓「戰／逃」多出第三個選項**繞路**，是 demo 中第一次把「苟」交給地形承載，也是第三幕血色試煉闖關的預演。

| 項 | 規格 |
| --- | --- |
| Map ID | 待建（新增） |
| 尺寸 | **120×120** |

#### 效能與體感備註（2026-09-27 評估）

| 項 | 結論 |
| --- | --- |
| **渲染效能** | 🟢 **非問題**。RMMZ 的 Tilemap 只渲染可視範圍＋邊界，**地圖格數不影響 draw call**。吃效能的是**事件數量**（尤其並行處理／自動執行）與 `EventsMoveCore` 的**離畫面事件自律移動**，不是尺寸 |
| **記憶體/檔案** | 🟢 可接受。120×120×6 層 ≈ 8.6 萬整數，`MapXXX.json` 約 300–500KB |
| **網頁載入** | 🟡 GitHub Pages 多一次數百 KB fetch，尚可；**勿再於此圖堆大量事件**（事件才是真正的成本） |
| **體感長度** | 🟠 **要留意**。一螢幕 27×15 ⇒ 120×120 ≈ **26 個螢幕**。第一幕一段支線若逼玩家走完會疲乏 |

**因應設計原則**：

1. **主線必經路徑控制在 3–5 個螢幕內**——入口到「夠用的採藥量」不該超過這個長度。其餘廣大區域一律設計為**可選深處**（高風險高回報），讓有根性的玩家自己去挖。
2. **迷宮本體約佔一半、其餘留實心岩壁/林牆**——產生器輸出後可大片封死，避免「哪裡都能走」的空洞感。
3. **遇敵自律移動只開畫面附近**（`EventsMoveCore` 有對應參數），避免 100+ 事件同時跑移動邏輯。
4. **深處瘴氣區可另用 region 限定隨機遇敵**（[TECH §1.4](../TECH.md) 慣例）：安全路徑看得見敵人可繞，踏進瘴氣才隨機遭遇——強化「越深越險」。
5. **防迷路**：入口設**採藥路標**（可重複讀，`a1_narr_maze_hint`）；各分區留可辨識地貌（枯樹／巨岩／水潭／獸骨），讓玩家能靠地標定位，而非純靠記憶。純迷宮的挫折感是 demo 的敵人。

**必備地貌**：入口（**接 M07 靈藥圃**）、蜿蜒岔路與**死路**、散布**採藥點**（越深越稀有）、若干**必經窄道**（擺 EV-15 野獸，必須面對）、若干**岔路口**（擺可繞開的野獸）、深處**獸窟**（可選高風險採藥區）、各區**地標**。
